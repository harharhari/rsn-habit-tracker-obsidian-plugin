# Hex color list

CSS Color Module Level 3 named colors (147 names, including spelling aliases).
Source: [W3C CSS Color 3, extended color keywords](https://www.w3.org/TR/css-color-3/#svg-color).
These are CSS web values: green is #008000, gray is #808080, and purple is #800080.
CSS4 rebeccapurple and transparent/currentColor are not included.

View in Obsidian Reading view to see shades. Copy a six-digit Hex Code into
habit-tracker-list.md yourself; this file never changes your habit list automatically.
Add custom rows to the table with a name and #RRGGBB code. The plugin fills the
Color Shade cell in Reading view even if you leave that cell empty. Invalid codes
are shown as invalid, never executed as CSS. Your vault copy is never overwritten.
